# Textures

`day.jpg`, `night.jpg`, `spec.jpg` and `moon.jpg` are resized/re-compressed versions of the planet textures shipped in the [three.js examples](https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets) (`earth_atmos_2048`, `earth_lights_2048`, `earth_specular_2048`, `moon_1024`), which are based on NASA imagery.

The MIT licence of this repository covers the **code**. Please check the licence/credit terms of the original textures before reusing them in another project, and replace them with textures you are sure about if you need to (any equirectangular JPEG of the same kind works: keep the file names).
